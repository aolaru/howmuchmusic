# Contributing

How Much Music is maintained as an open-source archive. Contributions are welcome, but there is no guaranteed review or release schedule.

## Good contributions

- Correct a factual error with a direct, public source.
- Replace a broken or weak source with a stronger primary source.
- Improve accessibility, navigation, performance, or maintainability.
- Clarify where public evidence ends and inference begins.
- Fix an image credit or licensing issue.

Broad catalog expansion, speculative earnings claims, promotional copy, and repetitive generated text are out of scope.

## Editorial requirements

- Make the claim no broader than the cited evidence.
- Prefer official records, primary sources, and directly relevant reporting.
- Do not present modeled values as royalty statements, audited results, or personal income.
- Identify uncertainty and private information that the source cannot establish.
- Preserve source titles, destinations, and attribution.
- Do not add an image unless its reuse terms and required attribution are documented.

## Development workflow

1. Create a focused branch from `main`.
2. Make one coherent change and avoid unrelated formatting edits.
3. Run `npm ci` when dependencies are not installed.
4. Run `npm run build` before submitting the pull request.
5. Explain the reader-facing change and list the sources used.

By contributing software, you agree that it is licensed under MIT. By contributing original editorial text or project data, you agree that it is licensed under CC BY 4.0. Do not contribute material you do not have permission to share.
