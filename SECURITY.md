# Security Policy

## Supported version

Only the current `main` branch and the live static site are supported. The project is maintained on a best-effort basis.

## Reporting a vulnerability

Do not disclose a security issue in a public GitHub issue before it can be reviewed. Email `info@howmuchmusic.com` with:

- A concise description of the issue.
- The affected URL, file, or workflow.
- Steps to reproduce it.
- The likely impact.

Editorial corrections and image-rights concerns may be reported through the same address and do not need to be treated as confidential security reports.
